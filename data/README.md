# Data Availability

This study draws on three census-tract–level sources. **ON-Marg (2021)** is publicly available; **DemoStats (Environics Analytics, 2022)** is licensed and cannot be redistributed by the authors; **Canadian Community Health Survey (CCHS) indicators** are available as public-use microdata and, where finer detail is required, via Statistics Canada Research Data Centres under their access policies. Because portions of the input data are licensed/controlled, the raw datasets cannot be posted publicly.

All analysis code, variable definitions, and processing scripts are available at [https://github.com/HIVE-UofT/diabetes-analysis](https://github.com/HIVE-UofT/diabetes-analysis), along with de-identified derived outputs. Researchers with appropriate access to DemoStats and CCHS can reproduce the analysis using our scripts.
